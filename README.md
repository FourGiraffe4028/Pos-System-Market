# 🛒 Pos-System-Market

A modern and intuitive Point of Sale (POS) system designed to streamline retail transactions, inventory tracking, and sales reporting. Built with CodeIgniter 4.

## ✨ Key Features

- **Fast Checkout & Billing:** Intuitive cashier interface with automated total and change calculation.
- **Inventory Tracking:** Real-time stock updates and product catalog management.
- **Sales Reporting:** Transaction history and sales performance overview.
- **User Roles:** Role-based access control for cashiers and administrators.

## 🛠️ Built With

- **Backend Framework:** CodeIgniter 4 (PHP)
- **Database:** MySQL
- **Frontend / Styling:** HTML, CSS, JavaScript

## 📋 Server Requirements

- PHP 8.1 or higher
- Required PHP Extensions: `intl`, `mbstring`, `json`, `mysqlnd`, `libcurl`
- MySQL / MariaDB
